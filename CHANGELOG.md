# Changelog

## 2.0.0 - Enhanced Hybrid Workforce Platform

- Renamed application to **DP World Hybrid Workforce Platform**.
- Added broader 3PL process library and custom process builder.
- Added upload capability for engineering models, process flows, and material flows.
- Expanded parameters by process type.
- Reworked Executive Cockpit chart layout, spacing, and operating-performance legend placement.
- Rebuilt 3D simulation visual style to be more professional and Omniverse-inspired, while remaining offline and dependency-free.
- Expanded OEM marketplace beyond humanoids to AMRs, robotic forklifts, robotic arms, vision systems, drones, and specialist warehouse robots.
- Added recommended hybrid automation mix and mix scorecards.
- Updated assistant prompts and responses for hybrid workforce strategy.

## 1.1.0 - Local deployment fix

- Replaced ES module runtime dependency with browser-compatible bundle for local file execution.
- Added standalone.html.
- Added local start scripts and deployment notes.
