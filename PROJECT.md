# Hybrid Workforce, version 2

The platform helps a warehouse choose, prepare, and improve a combination of people and technology.

Demand comes from process actions, timing, layout, an engineering model, demand, people, and cost. Supply comes from versioned products, tools, software, capabilities, evidence, and prices.

One case follows this path: Inputs → Process → Matches → Scenarios → Results → Deployment → Learning. The three main views are Executive, Evaluations, and Deployments.

The prototype must provide editable local records, hard fit checks, partial action assignment, bounded fleet comparisons, staffing and cash-flow calculations, reports, delivery planning, and observed-data entry. It must save and restore complete cases.

Assumptions: use controlled English; use EUR by default; use fictional engineering envelopes; make the tote case the main example; include AMR and kitting examples; use local persistence and an optional SQLite service. Example staffing and prices are assumptions. A named AGIBOT model and supported control stack remain unknown.

CAD interpretation, real physics, robot model training, live telemetry, and hardware transfer are external services. The prototype must show their input/output needs and connection state.
